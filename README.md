## Cómo ejecutar

Compilar:
g++ ComparacionAlgoritmosOrdenamiento.cpp -o ordenamiento
Ejecutar:
./ordenamiento

O ejecutar el archivo ComparacionAlgoritmosOrdenamiento.exe
